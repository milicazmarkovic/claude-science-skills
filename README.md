# Claude Science Skills

1. ketcher-canvas-default

   Use this skill to load an empty Ketcher canvas in Claude Science and use it to edit structures in place and talk to your AI agent through these structures. Agent can see and edit the canvas as well.

### How to add skill? 

In Settings of Claude Science, in Skills section there is a button in top left corner where a new skill can be added. In dropdown there is an option to upload files to create skill. 
Here add SKILL-ketcher-canvas-default.md first, then in references add kernel.py for use of some basic Indigo functionalities along with Ketcher due to better compatibility.
